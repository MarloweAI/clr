# Post-run interpretation correction for55349

The frozen runner explicitly removed value readbacks and guard checks from preparation, but `Signal::reset()` still called `hsa_signal_store_relaxed`. That API calls `core::Signal::Convert` (signal.h311), which reads GPU-resident SharedSignal validity/IPC/core_signal metadata before invoking BusyWaitSignal::StoreRelaxed. Thus the source comment claiming no CPU internal access before drainage was too broad; it describes explicit checks but overlooks hidden API reads. The7.136us/pair g1 and4.748 g50 preparation numbers include this lookup. They are not a physical store-only cost floor. Raw timing, source, packet topology and correctness evidence remain unchanged. No new result or qualification is claimed by this correction. The cached-pointer matched experiment in siblinghassan-boundary-reset-20260919 addresses this exact distinction.
