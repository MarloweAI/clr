# Per-graph boundary token experiment

Goal1 remains incomplete;55272 is a rejected configuration shortcut. This test preserves explicit graph boundaries in original Q/K packet replay, unlike earlier flattening across all200pairs. For g1 it has200 entry/final joins, for g50 four. Original captured packets, kernels/arguments, scheduler/data and AGENT scopes are retained. The new entry/final ANDs are ordered SYSTEM/SYSTEM, side entry is SYSTEM acquire, within-graph joins stay NONE/NONE followed by original AGENT kernels. Final join waits the actual final K token; ordering covers final Q. Main queue's next entry follows that join, and the side waits that next entry. Thus every next graph waits both prior branches.

Modes0/1/2 are normal pooled host GPU_ONLY / private host-page / identical private GPU-local-page tokens. Each run has2*units+graphs unique private/pooled GPU completion tokens and graphs ordinary host final signals. Host/local private allocation extents, semantics and reset protocol match. This isolates storage in a new entry/final topology; it does not separately estimate the benefit of removing per-lane host retirement. One host completion per graph is a lower-layer feasibility model, not yet a safe HIP host-lifetime implementation.

Reset uses only host stores while both queues and all previous work are fully drained. It writes1 and zero timestamps, then SFENCE before AQL release publication and the ordinary ROCr doorbell. No CPU internal readback occurs between timer start and complete GPU drainage. Every exact zero and guard is checked afterward. Primary total starts before all resets and ends after final host completion plus both queue read indices drain. No deliberate gate hold or excluded per-graph preparation. Readback/guard overhead is correctness-only after retirement. Mode0 has the same reset stores too.

Visibility contract is bounded to this x86/gfx950 private build: private allocation is public local fine-grained, AllocateUncached/NonPaged/Direct. KfdDriver propagates Uncached and forces CoarseGrain/ExtendedCoherent0. BusyWaitSignal reset is atomic Store, not CPU locked RMW. ROCr atomic_helpers x64 release fences SFENCE; AqlQueue ordinary doorbell also SFENCEs before MMIO, explicitly without readback. ROCr also supports local fine-grained uncached queue descriptors with these publication primitives. Source identities are retained in visibility-source.json; this supports the diagnostic store/publication protocol, not a universal claim about arbitrary GPU memory or another architecture. Runtime graph kernarg HDP/readback paths use distinct memory/configuration and must not be generalized away.

Exact packet audit checks every byte against original templates plus enumerated signal addresses and entry/final packets, matched private extents, uniqueness, graph-to-graph waits, ring wrap and completions. Both g1/g50 receive full4rounds×7cells×8trials=448timings total, including separate profiled controls and HIP reference. Profile endpoints only diagnose dispatch envelopes; no independent completion-ready timestamp or wave-occupancy claim. Changed/restored inputs and3570 numerical rows screen data correctness. Raw publication is ahead of GPU work and has no per-graph HIP CPU bookkeeping; the HIP reference is a different submission boundary, not a causal denominator.
