# Graph-owned GPU dependencies: first HIP integration

The lower-layer placement/reset experiments passed. This candidate tests the actual unchanged HIP graph launch boundary, with one reset per launch and ordinary host lifetime handling. It is a default-off diagnostic, not a production package.

Eligibility is structural: flat captured kernel-only graph on one GPU, at least two physical queues, all enabled packets ordered, producer release/consumer acquire at least AGENT, no profiling/activity/host/child/event nodes or hidden heap. Existing segment assignment and submission order are preserved. Disabled or unsupported graphs fall back before publication. Graphs without an actual internal cross-physical-queue dependency also keep the original path because the proposed tokens would have no consumer. There are no kernel names, shapes or timing thresholds.

Each in-flight graph launch owns a generation of real private GPU-only ROCr signals and an immutable fine-grained pointer table. Separate short host lowering and pool locks permit asynchronous GPU launches. Generation allocation is outside the callback lock. A builtin scatter kernel resets values/timestamps with an explicitly ordered SYSTEM/SYSTEM packet on the launch stream. Ordinary reset completion is retained as the root frontier. Original captured packet copies carry local completion only on actual segment tails; direct ordered NONE/NONE ANDs consume internal dependencies without tracker/native admission or CPU local-signal loads. Queue idle tracking also excludes the local handles.

One ordinary AccumulateCommand per touched logical stream retains host retirement. Every side tail is joined by a final marker whose callback was registered before any GPU publication. Callback returns the generation only after GPU completion, outside the host launch lock; final reference release occurs outside the pool lock. Any published prefix is retired through the same join on failures. Unproven asynchronous failure quarantines the generation and retains its owner. No per-launch host GPU synchronization is added. Graph updates revalidate packet eligibility, and disabled graphs use the established path.

The first builtin implementation performs normal kernel argument preparation each launch; this CPU cost must be measured. Real g1/g50, submit and total time, queued bursts, graph update/disable/failure and destruction need validation before any qualification. Private HSA2899 is required; same-byte host-page arena control separates placement from restructuring. No full-model or broad holdout until unchanged Hassan improves.
